## 🧭 About Me

- 🎓 Electronic Information Science student interested in **autonomous systems, embedded development and interactive software**
- 🚁 Working with a student team on secondary development of a **Nonconvex-α educational research drone**
- 🗺️ Learning ROS 1, PX4, MAVROS, Livox Mid-360, Faster-LIO and local trajectory planning through real hardware
- 💻 Building full-stack tools with Vue, TypeScript, FastAPI, Supabase and REST APIs
- 🎸 Exploring music-tech, playable theory, Web Audio and creative coding
- 🧠 Learning by keeping reproducible backups, documenting experiments and turning ideas into working systems

### 🚁 Nonconvex-α Standard Drone

![C++](https://img.shields.io/badge/Core-C%2B%2B-00599C?style=flat-square)

A student-team source snapshot and long-term backup repository for learning, secondary development and change tracking on a Nonconvex-α educational research drone.

Current work includes Livox Mid-360 localization, Faster-LIO, Diff-Planner, waypoint missions, simulation and a safer Git-based team workflow.

**Focus:** preserve a recoverable baseline, understand the flight stack and validate every change from simulation to controlled flight.
